支持的存档文件与使用方法

本修改器仅支持游戏目录中 USERARCHIVE 文件夹内的单局 JSON 存档：

com.gametree.sultan.pd / SultansGame / SAVEDATA / [代表当前账户的一长串数字文件夹] / USERARCHIVE / [000.json、001.json……0XX.json]
  1. 先退出游戏或回到主菜单。
  2. 进入上面的 USERARCHIVE 文件夹，把要修改的 JSON 存档手动复制出来，并保留原始备份。
  3. 把复制出来的文件导入本修改器；修改完成后下载新存档。
  4. 保持原来的文件名，再手动把新存档替换回 USERARCHIVE 文件夹中的对应文件。
ⓘ 本工具不会自动读取、上传或覆盖游戏目录中的文件；导入和替换都需要你手动完成。
